# Moodify

A full-stack music recommendation application that recommends songs based on the user's selected mood using React, Node.js, and the Spotify Web API.

## Live Demo

[View the live application](https://moodify-phi-lyart.vercel.app/)

## Overview

This project is a web-based music recommendation application that allows users to select a mood and receive song recommendations based on their selection. React and Vite are used to build the frontend application, while a Node.js backend handles requests to the Spotify Web API.

## Tech Stack

- React
- JavaScript
- Vite
- Node.js
- Axios
- Spotify Web API
- HTML
- CSS

## Features

- Mood-based music recommendations
- Spotify Web API integration
- Node.js backend
- React frontend
- API request handling with Axios
- Multiple mood selections
- Responsive user interface
- Interactive React components
